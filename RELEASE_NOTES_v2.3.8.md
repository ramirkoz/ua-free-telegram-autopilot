# Autopilot 2.3.8 — без чужих зображень у новинах про логотипи

## Виправлено

- «ПРОДАНО!» — операторські публікації #88700 (Apple MacBook Pro) і #89671 (Ed’s Electric) містили по два зображення; одне стороннє зображення повторювалося в обох новинах від Creative Bloq.
- Для публікацій про **один логотип / айдентику** останній редакційний медіагейт тепер обирає одне найбільш підтверджене першоджерелом зображення; CSS-галерея чи позначка «hero» самі по собі не дають права додати другий візуал.
- Якщо джерело має **явно підтверджену schema.org-галерею**, вона лишається повною. Звичайні фотогалереї інших тематик, Telegram-альбоми та відео не урізаються.
- Справжні зображення логотипів, чиї файли містять слово `logo`, більше не відкидаються лише за цю назву, **якщо назва/підпис файлу відповідає конкретному бренду в оригіналі статті**. Логотипи сайту, аватари, рекламні банери й чужі медіа залишаються заблокованими.
- Чинний міжстатейний фільтр повторних зображень збережено. Додано окрему причину відсіву `identity_story_unproven_extra_238`, щоб перевіряти ефект за телеметрією, а не лише за числом фото.

## Не змінено

- Інтервали каналів 45/30/5 хвилин, редакційні політики, маршрути AI, Fact/Media hard gates, збереження Data та історія Telegram COMMITTED/UNKNOWN.
- Не змінюємо вже опубліковані пости, не повторно відправляємо старі статті.

## Встановлення

- Зупинити 2.3.7, розпакувати новий повний Windows Portable в окрему папку; імпортувати стару Data штатним майстром, без ручного копіювання. Не запускати два екземпляри одночасно.
- Перевірити LIVE supervisor version=2.3.8, 3/3 працівники і збирачі, та нові логотипні публікації. Успішне CI не дорівнює LIVE-прийняттю.
