# Autopilot 2.2.53: verified details from explicit Telegram news links

Based on six actual operator v2.2.50 posts and the safe incompleteness veto in 2.2.52.

- **Recover useful local news rather than only reject teasers.** For an eligible fresh, previously unseen Telegram post whose original text explicitly contains **one** `Детальніше: https://...` link and lacks promised **new street names or water outage addresses**, fetch the exact linked HTTPS page once before SQLite insertion and AI selection.
- **Bounded and secure:** maximum **2 external HTML fetch attempts across the entire channel collection cycle**, **1 per Telegram source**, **8 seconds per request**, **800 KB**, maximum one redirect, same host only, no IP literals or local/internal hosts. Existing `network.fetch_url` pins DNS to verified public IPs, rejects credentials/invalid ports and non-public redirect targets. HTTP403, blocked paywalls and unavailable text remain unavailable. No URL discovery/search, no background retry storms, no alternate blocked-site access.
- **Identity and provenance:** require a related article headline, at least 190 characters of body, and the **actual promised names/addresses** so v2.2.52's completeness veto would clear. Store transparent `explicit_linked_article_253` origin metadata in existing layout JSON. Preserve exact Telegram post URL, external ID, publish timestamp and Telegram media; **never import the linked page's images**. No additional AI call. One trustworthy article's text is presented explicitly as linked website evidence, never falsely as original Telegram message text.
- **Fail-closed:** any mismatch/unavailable/page listing/cross-domain redirect/insufficient details retains the original Telegram raw source and v2.2.52 rejection. Existing short alerts, non-Telegam feeds, manual history and already known items are untouched.
- **Tests:** successful named-street/address recovery, false URL/SSRF/redirect and nonarticle controls, no uncontrolled web requests or media cross-ownership, incomplete-page remains rejected, explicit two-token channel budget.
- No changes to source rosters or operator priorities, 45/30/5-minute intervals, $3/day or $20/month AI budgets, historical Data/SQLite schema, receipt ledger, quarantined UNKNOWN or Telegram replay.
- **Acceptance boundary:** CI and Windows ZIP are delivery gates. LIVE editorial acceptance requires new operator 2.2.53 source→draft→final posts; 2.2.52 still runs on Windows until operator installs. Not a general-purpose web crawler, not full natural-language entailment, not a guarantee the external article is correct.
