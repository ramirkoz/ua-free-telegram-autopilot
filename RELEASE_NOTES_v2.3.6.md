# UA FREE Telegram Autopilot 2.3.6 — повний реліз на основі операторської 2.3.5

**Дата: 03.11.2026.** База: точний користувацький Windows Portable `Autopilot_2.3.5_Portable(1).zip` із збереженим виконуваним Python 3.12/Windows середовищем, усіма модифікаціями 2.3.0–2.3.5 та штатним майстром імпорту `Data`.

## CTRL+UA і ПРОДАНО!
- Критерії відбору перевизначені за реальними **200 ручними оцінками** редактора: 47 відібраних із 100 для CTRL+UA і 31 зі 100 для ПРОДАНО!.
- Прибране послідовне суб'єктивне вето `EDITORIAL_VALUE_REJECT`, `SCIENCE_AUDIENCE_REJECT`, `SOLD_VALUE_REJECT` / `SOLD_CATALOG_ONLY` **після** позитивного тематичного схвалення для двох явно налаштованих редакційних профілів.
- У CTRL+UA цікаві наукові і технологічні новини не повинні доводити «революційність»; у ПРОДАНО! незвичайний продукт, форма, дизайнерська ідея чи концепція не потребують «вірусності» або маркетингового ROI. Рутинний PR і порожні анонси залишаються небажаними.
- Нові правила каналу `purpose/audience/selection/rejection/selector/writer` встановлюються **однократно після штатного імпорту**, до запуску колекторів, із точним бекапом старих налаштувань у meta SQLite та окремою функцією відкату. Редакційний опис каналу в UI також оновлюється.
- Науковий/комерційний каталог фактів, фактологічні тести, source-day age fencing, конкретний первинний текст, media QA, дедуплікація та Telegram delivery/UNKNOWN не вимикаються.

## ЗАПОРІЖЖЯ | ГРОМАДИ
- Відсікаються непрофільні політичні оцінки про США без локального факту та непідтверджена спекуляція про Борщагівку, якщо новина не містить власної місцевої події.
- «Чутно реактив» без підтвердженого результату не перетворюється на текст про ракету чи літак із вигаданими порадами.
- SOURCE→FINAL фактологія не дозволяє загубити наведені в оригіналі конкретні інтервали графіків відключення світла.
- Високоточна крос-джерельна дедуплікація міжнародного спортивного медального дайджесту за **трьома підтвердженими іменами спортсменів**, двома видами спорту, двома країнами та часовим вікном; #88747 / #88765.
- Інші моніторингові правила і cadence залишено незмінними.

## ПРОДАНО! / RSS
- У 2.3.5 Trend Hunter не відновився через помилку: сервіс FeedBurner для Trend Hunter сплутано з іншим видавцем Design Milk. Виправлення в 2.3.6 спрацьовує лише якщо **в записі міграції 2.3.5** є точна позначка `feed_host_in_use`, старий URL і вимкнений оригінальний source рядок.
- Ідентичність source, старі статті, telegram-delivery ledger і ручно змінені / альтернативні RSS не змінюються. Чотири нові джерела з 2.3.5 (designboom, Dezeen, Packaging of the World, Colossal) збережені.
- HTTP_403 у The Dieline не оголошено виправленим і не обходиться підміною мережевого джерела.

## Встановлення та приймання
1. Зупиніть і закрийте 2.3.5. Не видаляйте її.
2. Розпакуйте **повний** Windows Portable 2.3.6 у нову, порожню папку. Не переносіть `Data` вручну.
3. Запустіть `UA_FREE_Telegram_Autopilot.exe`. Через вбудований майстер імпорту виберіть папку старої 2.3.5 або її `Data`.
4. Переконайтеся, що відновилися три канали, налаштування/credentials/Telegram delivery. Не перевідправляйте історичний `UNKNOWN`.
5. Перевірте 3 workers + 3 collectors, нові природні статті та публікації. Перевіряйте окремо якість CTRL+UA, ПРОДАНО! та ГРОМАД; для ГРОМАД особливо графіки й повтори.
6. Щоденний human-in-the-loop аналіз: останні по 100 нових матеріалів обох редакційних каналів, галочки редактора, порівняння з фактичними рішеннями системи, зміни ProductVault за повторюваними фактами. Оцінювання не підмінює фактичної достовірності.

**Валідація:** локальні Python 3.13 / Linux AST/compileall та ізольовані тести для нового коду; відтворено факти помилок за operator SQLite READ-ONLY. ZIP CRC перевірка, SHA256. Нативне Windows GUI/Defender/публікації на ПК користувача тут недоступні; вважати операторським реліз-кандидатом до першого LIVE-приймання. Системний Python для Windows Portable не потрібен, оригінальний EXE/portable runtime не змінювався.

**Безпека:** ZIP не містить `Data`, user SQLite, Telegram credentials, API keys. Збережені 45/30/5 хв, бюджети, рівень підтвердження джерела, модуль доставки та UNKNOWN.
