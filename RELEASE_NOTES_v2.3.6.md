# Autopilot 2.3.6 — повний редакційний перезапуск трьох каналів

**Зміст:** нові редакційні політики CTRL+UA та «ПРОДАНО!» на основі 200 ручних оцінок редактора; підтверджені ранкові виправлення «ЗАПОРІЖЖЯ | ГРОМАДИ»; відновлення всього портфеля комерційних RSS із локальної 2.3.5 та усунення конфлікту FeedBurner.

## Нові правила відбору
- CTRL+UA: одна зрозуміла перевірка тематичної цікавості науки, космосу, ШІ, робототехніки, кібербезпеки та технологічних предметів, замість нескінченних додаткових суб’єктивних veto за «революційність».
- ПРОДАНО!: цікавий дизайн, оригінальний продукт, концепція, креатив та упаковка не потребують доведеної вірусності чи продажів. Рутинний корпоративний PR і реклама без ідеї лишаються небажаними.
- Зберігаються Fact Guard, первинне джерело, перевірка події, фактичної повноти, якість українського тексту, медіа й Telegram delivery. Рішення редактора не обходить перевірку достовірності.

## ГРОМАДИ
- Відхилення вузько визначених сторонніх політичних і непідтверджених непрофільних сюжетів незалежно від бренду каналу-перепостувача.
- Первинні неперевірені «чутно реактив» без встановлених фактів не перетворюються на повідомлення про ракети чи літаки.
- Коли джерело містить конкретні графіки електровідключень, фінальний текст не може загубити всі точні часові інтервали.
- Крос-джерельні повтори одного звіту про медалі запорізьких спортсменів виявляються за збігом конкретних імен, видів спорту, країн і часового вікна.

## Сумісність із операторською 2.3.5
- Офіційна GitHub база перед релізом — 2.2.64; локальна встановлена 2.3.5 мала лише неоприлюднену міграцію комерційних джерел згідно із ProductVault RELEASE_2.3.5.md.
- Новий одноразовий крок `commercial_sources_236.py` відтворює чотири джерела designboom/Dezeen/Packaging of the World/Colossal, зберігає Dieline і поновлює Trend Hunter як окремого видавця від Design Milk, хоча обидва використовують FeedBurner. Не дублює вже імпортовані RSS.
- Раніше накопичені Data, публікації та Telegram receipts не перезаписуються. Запускайте Portable у новій папці та використовуйте **вбудований імпорт попередньої Data**; не копіюйте її вручну.
- Зміни редакційних налаштувань записуються лише після першого запуску та мають збережену в Data/meta точну резервну копію попередніх полів. Усі інші канали не переналаштовуються.

## Релізні вимоги
- Тести на ізоляцію каналів, ідемпотентність міграції, джерельну фактологію, крос-джерельні дублікати, успадкування 2.3.5.
- Повний GitHub CI; Windows Portable GUI/Defender; підпис launcher, ZIP/SHA256.
- Operator LIVE-перевірка після встановлення окрема від успішної побудови. Не запускати повторні відправлення історичного UNKNOWN.
