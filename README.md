# UA FREE Telegram Autopilot v2.3.48 (owner selection + independent regional newsroom)

Windows Portable автопілот для збору, відбору, редактури та публікації контенту в Telegram з опційним кроспостингом у Facebook.

## Редакторський відбір 2.3.48

Профіль власника за 3 627 оціненими українськими заголовками (16–22.11.2026): CTRL+UA 1 482 зелених із 2 494, ПРОДАНО! 611 із 1 133. Незелене = відхилено редактором. Зелене означає зацікавленість, не дозвіл публікувати всі новини або порушувати TTL.

«ГРОМАДИ»: source-only захист від порожніх привітань та протоколів без рішень, журналістський порядок фактів, існуючий фінальний редактор для коротких казенних текстів; не додавати неіснуючих фактів.

Непорушно: налаштування каналів, 30/30/5 хв, OpenRouter $3/день і $20/місяць, Data/SQLite/Telegram/2 UNKNOWN/Content Tool. LIVE редакційне приймання окреме від CI.

## Архітектура

- `telegram_autopilot/v2` — активний runtime, канали, черга, editorial pipeline, Supervisor та updater.
- `Data` — тільки користувацькі дані: база, конфігурація, журнали, кеш і службовий стан.
- `Tools` — відтворювані важкі інструменти: LanguageTool, JRE і Codex. Вони не входять у Data і не мігруються зі старих версій.
- Anti-Slop, мовні/граматичні блокери, paragraph/corruption QA та фактова перевірка працюють у фінальному V2 editorial pipeline.
- AI Router використовує зовнішні провайдери та local fallback; Codex через ChatGPT є резервним trusted provider, а не першим маршрутом для кожної дрібної задачі.

## Перший запуск / міграція

Нова чиста папка не потребує копіювання старої `Data`. На першому запуску можна вказати стару папку Autopilot або її `Data`; імпортер у режимі read-only переносить лише довготривалі дані: канали, правила, джерела, історію матеріалів/публікацій, feedback та зашифровані credentials. Логи, cache, Tools, provider cooldowns і runtime queues не переносяться.

## Portable layout

```text
UA_FREE_Telegram_Autopilot.exe
_runtime/
Tools/
Data/
VERSION.txt
PUBLIC_VERSION.txt
V2_VERSION.txt
README.txt
```

При штатному оновленні `Data` і `Tools` зберігаються. При закритті V2 runtime явно завершує власний LanguageTool JVM, щоб стара папка не залишалася заблокованою `java.exe`.

Поточний код: **v2.3.48**, зберігає AI Gateway та захист 2.3.43, зберігає жорсткий фільтр ремонту, подарунків, соусів і мемів, додає абсолютне source-only вето на рецепти/кулінарні поради в усіх каналах та посилює редакторський стиль на етапі selection та перед Telegram, включно з готовими READY. Перед публікацією/установленням потрібні незалежний GitHub CI, повний Windows Portable, перевірка запуску і Microsoft Defender, а також приймання реальних публікацій власником. Встановлена операторська версія перевіряється за LIVE телеметрією, а не за кодом репозиторію. Інтервали 30/30/5 хв, витратні ліміти, Data, Telegram COMMITTED/UNKNOWN і правила безпечної міграції незмінні.

## Редакційний P0 v2.3.47 — виміряний результат і чистий текст

- Реальний інцидент #107785 / Telegram #1327: багатосторінкове дослідження GTA перетворилося на опис методики без результатів. Для довгих дослідницьких статей автор/редактор отримують дослівні фрагменти результатів із SOURCE, а їх відсутність у methods-only тексті відсікається перед READY та перед Telegram. Жодних вигаданих результатів або додаткових AI-викликів.
- Реальний інцидент #107861 / Telegram #1328: `*Psychology of Music*` відображався буквально. Усі канали у звичайних текстових повідомленнях та media caption конвертують обрамлене `*назва*` / `**назва**` на українські лапки `«назва»`; операторські математичні вирази, буліти й несформовані маркери не змінюються.
- Код і CI/Windows/Defender не є самі по собі доказом редакційного приймання. Див. `RELEASE_NOTES_v2.3.47.md`.

## Редакційний P0 v2.3.46 — один інфопривід, не два донорські пости

- Моніторинг **не** публікує загальні привітання, емоційні звернення чи календарні тексти про дитинство без самостійної фактичної події.
- Сусідні Telegram-повідомлення одного донора про той самий сюжет проходять source-owned перевірку: розрізняємо реальний новий результат і повторення попереднього.
- Перевірка працює до AI і повторно перед Telegram для історичних READY. Лише для моніторингового профілю; матеріальні новини про дітей, допомогу, евакуацію, безпеку і нові послуги зберігаються.
- Два повідомлення Михайлівської громади 20.11.2026 (article 107571 / 107572) є P0-регресійним прикладом.
