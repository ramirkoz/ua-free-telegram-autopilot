# UA FREE Telegram Autopilot v0.1.0-rc9

Окремий Windows portable продукт для автоматизованого збору, редакційної AI-обробки та публікації технологічних новин у Telegram через Telegraph.

## Поточний стан

RC9 залишається поточною версією. 17.08.2026 застосовано hotfix черги без зміни номера версії:

- свіжі матеріали зі статусом `new` завжди обробляються раніше за історичні `retry`;
- старі `retry` більше не можуть заблокувати всю pending-чергу;
- повторні помилки отримують backoff 2 / 5 / 15 / 30 хвилин;
- після 5 невдалих спроб матеріал переходить у `error`, а не крутиться безкінечно;
- до наявної RC8/RC9 `Data` додаються лише службові поля `retry_count` і `next_retry_at`, без скидання каналів, джерел, історії чи токенів.

## Ключові принципи

- продукт повністю окремий від UA FREE Content Tool;
- наявна `Data` попередньої версії зберігається;
- AI Router, український rewrite/translation і Ollama fallback адаптовані з перевіреної архітектури Content Tool;
- Media Engine відкидає рекламу, банери, логотипи та нерелевантні зображення;
- якщо якісного медіа немає, матеріал публікується без випадкової картинки.
