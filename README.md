# UA FREE Telegram Autopilot v0.1.0-rc10

Окремий Windows portable продукт для автоматизованого збору, редакційної обробки та публікації технологічних і науково-популярних новин у Telegram.

## Що нового в RC10

- **Evidence Pack**: довга стаття більше не обрізається механічно з початку. Локальний детермінований відбір зберігає лід і важливі речення з числами, назвами, одиницями, атрибуцією та high-risk claims.
- **Fact Guard**: після звичайної перевірки років/чисел додатково блокує вигадані латинські назви/моделі та непідтверджені підсилення на кшталт «перший», «найбільший», «найшвидший», «найпотужніший» або «рекорд».
- **Source Health**: у вкладці «Джерела» видно стан, час останньої нової знахідки, yield останньої перевірки й накопичені помилки.
- **Стійкий audit trail**: ключові етапи збору, редакційного gate, рерайту й Telegram-публікації зберігаються локально між запусками; токени маскуються.
- **Без зміни механізму публікації**: черга, new-before-retry, backoff, 900/4096, Telegram send/recovery та Ollama fallback залишені з RC9.

## Поточний production-формат

RC10 зберігає перевірений прямий Telegram-конвеєр RC9:

`джерело → очищена стаття → локальний editorial/dedup gate → один AI-рерайт → факт-QA → один медіафайл або без медіа → Telegram`

Ключові правила:

- жодних Telegraph-сторінок у production pipeline;
- один Telegram-пост = професійний український научпоп/техножурналістський текст без окремого заголовка;
- якщо є медіа: один медіафайл + завершений пост до 900 символів;
- якщо медіа немає: одне текстове повідомлення до технічного максимуму Telegram, 4096 символів;
- незавершений AI-вивід не обрізається: він відхиляється та переписується, поки не завершується повним реченням;
- максимум один перевірений релевантний медіафайл;
- неправильне або сумнівне медіа гірше за пост без медіа, тому реклама, банери, `Click to follow`, логотипи, related/recommended assets і випадкові картинки відкидаються;
- дати, роки та числа перевіряються детерміновано проти джерела перед публікацією;
- відносні дати прив'язуються до дати публікації джерела;
- AI Router використовує bounded failover, provider cooldown та локальний Ollama fallback;
- адаптивний readability verifier не витрачає додатковий AI на хороший перший рерайт, але для посереднього валідного тексту просить другу версію, бажано в іншого провайдера, і залишає більш читабельну;
- `new` матеріали мають пріоритет над старими `retry`, повтори мають backoff і ліміт;
- існуюча portable `Data` зберігається без destructive migration.

Поточна версія: `0.1.0-rc10`.
