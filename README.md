# UA FREE Telegram Autopilot v0.1.0-rc42

Windows portable застосунок для збору новин із кількох незалежних Telegram-каналів, редакційного відбору, безпечного AI-рерайту українською та прямої публікації в Telegram.

## Production-конвеєр RC42

`джерело → source-health/backoff → exact/event dedupe → channel-specific editorial profile/weights → media relevance → Evidence Pack → RU editorial bridge (optional fallback) → fresh UA author → hard Fact Guard/UA safety → soft quality repair → Telegram`

## RC42: редакційна політика належить каналу

RC41 виявив архітектурну помилку: CTRL+UA-шні технологічні категорії та їхні ліміти були глобальними. Для багатоканальної програми це неправильно. RC42 прибирає глобальні `cyber/AI/space/...` частки з production-поведінки.

Для кожного каналу в редакторі каналу тепер окремо задаються:

- **Редакційний профіль** — вільний текст: тематика, аудиторія, що публікувати/не публікувати, бажаний стиль.
- **Редакційні ваги** — список, який оператор створює руками. Для кожного рядка задається власна назва категорії та вага `0–100`.
- Ваги відносні: `30 / 20 / 10` автоматично нормалізуються до `50% / 33.3% / 16.7%`. Сума не зобов’язана дорівнювати 100.
- Вага `0` означає: автоматично не публікувати матеріали цієї категорії.
- Якщо список ваг порожній, тематичний balance gate для цього каналу не застосовується взагалі.

Приклад CTRL+UA може мати свої `AI`, `Tools`, `Robotics`, `Science`, `Cyber`. Майбутній Marketing-канал може мати `SEO`, `Social media`, `Advertising`, `Analytics`, `MarTech`. Вони не впливають один на одного.

### Як визначається категорія

- Спочатку програма пробує локальний детермінований збіг із назвою категорії.
- Якщо назва не присутня буквально, невеликий AI-класифікатор семантично вибирає одну з **операторських** категорій.
- Codex для цього допоміжного дешевого кроку не використовується.
- Якщо класифікатор тимчасово недоступний, публікація не блокується лише через це.
- Категорія зберігається біля статті в локальній SQLite і rolling balance рахується тільки всередині цього каналу.
- Ваги є цільовими частками, а не крихкими жорсткими квотами: є невеликий допуск на один пост у короткому вікні.

### Універсальний newsworthiness gate

Старі tech-only правила на кшталт глобального штрафу за маркетингові релізи більше не визначають усі канали. RC42 лишає тільки універсальний сміттєвий фільтр для buying/affiliate roundups і явно sponsored/affiliate source material. Тематику визначають профіль і ваги конкретного каналу.

## Редакторський міст RC40, збережений у RC42

- Перший AI-прохід пише внутрішню російську редакторську чернетку і шукає сильний факт, конфлікт, наслідок, дивну деталь або людський епізод.
- Російська чернетка не є джерелом фактів. Якщо bridge і SOURCE суперечать один одному, SOURCE має абсолютний пріоритет.
- Другий прохід пише український пост заново; буквальний переклад речення за реченням заборонений.
- Якщо bridge-провайдери недоступні, фінальний автор може працювати безпосередньо з SOURCE.

## Стиль і safety

- Немає фіксованої кількості слів, речень або абзаців.
- Для поста з фото лишається hard limit 900 символів; довжина не добивається водою.
- Факти, нові числа/сутності, обірваний текст, ненормативна українська та структурна корупція залишаються hard blockers.
- Safe-кандидат із неідеальним стилем може отримати один targeted copy-edit repair; невдалий repair не вбиває безпечний оригінал.
- Evidence Pack, Fact Guard, number/year checks, attribution/relationship protections, Ukrainian hard gate та media-required publishing залишаються обов’язковими.
- Cache marker: `telegram-post-v27`, тому pending/retry старих drafts перегенеровуються через RC42 policy.

## AI Router

- Категорійний classifier використовує Gemini/Groq/NVIDIA/Cloudflare/local без Codex.
- RU bridge спочатку пробує Gemini/Groq/NVIDIA/Cloudflare/local без Codex.
- Фінальний український автор: `Codex / ChatGPT → Gemini`, а при їх недоступності `Groq → NVIDIA` під тим самим hard Fact Guard.

## Медіа

- Без релевантного фото/відео новина не публікується (`SKIP_NO_MEDIA`).
- Featured/OG image потребує story-specific semantic evidence.
- Якщо Telegram відхиляє медіа, текстовий fallback заборонений.

## Дані та portable-режим

RC42 робить лише адитивне оновлення SQLite: додає `channels.editorial_weights_json` і `articles.editorial_category`. Існуючі канали, джерела, історія та токени не видаляються.

Для оновлення розпакуйте RC42 у нову папку та перенесіть туди **всю папку `Data`** з RC41. Не накладайте runtime-файли поверх старої збірки.
