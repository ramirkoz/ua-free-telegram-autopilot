# UA FREE Telegram Autopilot v0.1.0-rc9

Окремий Windows portable продукт для автоматизованого збору, редакційної обробки та публікації технологічних новин у Telegram.

## Поточний стан

RC9 містить production hotfix для черги та AI-контуру після живого Windows-тесту 17.08.2026.

- існуюча `Data` попередньої версії зберігається;
- свіжі `new` матеріали мають пріоритет над старими `retry`;
- `retry` має backoff і ліміт повторів, тому старі помилки не блокують новини;
- AI Router використовує bounded failover, provider cooldown і робочі production-моделі;
- NVIDIA-моделі, які у live-тесті повернули HTTP 410 / end-of-life, вилучені з production route;
- рішення AI приймаються через компактний tolerant line protocol, JSON лишився тільки для сумісності;
- український rewrite використовує простий маркерний формат `ЗАГОЛОВОК / АНОНС / ТЕКСТ`, а не залежить від ідеального JSON;
- локальний Ollama отримує суттєво коротший prompt і обмежений час виконання;
- один цикл Autopilot має ліміт AI-спроб і wall-clock deadline, тому серія AI-помилок не може годинами блокувати продукт;
- Media Engine відкидає рекламу, банери, generic logo/Cocoon assets і вибирає релевантне editorial media;
- якщо надійного зображення немає, публікація йде без випадкової картинки.

## Безпека Data

`Data`, SQLite-база, логи, токени, `secrets.secure` і `secrets.key` не комітяться в GitHub. Для тестування нової portable-збірки використовується повна копія робочої `Data`.
