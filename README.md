# UA FREE Telegram Autopilot

Окремий Windows portable продукт для автоматизованого збору, редакційної обробки та публікації технологічних новин у Telegram.

Поточний стан: новий репозиторій ініціалізовано. Робочий RC9 розробляється у окремій development-гілці та не буде промотований у `main` до живого acceptance test на наявній `Data`.

Ключові принципи:
- продукт повністю окремий від UA FREE Content Tool;
- наявна `Data` попередньої версії зберігається;
- AI Router, український rewrite/translation і Ollama fallback адаптуються з перевіреної архітектури Content Tool;
- Media Engine має відкидати рекламу, банери, логотипи та нерелевантні зображення;
- якщо якісного медіа немає, матеріал публікується без випадкової картинки.

Дата ініціалізації репозиторію: 17.08.2026.
