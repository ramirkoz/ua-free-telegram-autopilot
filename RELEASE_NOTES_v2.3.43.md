# UA FREE Telegram Autopilot v2.3.43 · consolidated Windows Portable release candidate

Дата: 19.11.2026. Основою є `main` v2.3.42 (AI Gateway) та PR #322 (власник відхилив CTRL+UA #2060). Цей release candidate НЕ є підтвердженням операторського LIVE-приймання.

## 1. AI Gateway (успадковано з 2.3.42)

- Одночасно до 3 робочих OpenRouter-викликів під загальним `BoundedSemaphore(3)`, інші провайдери мають консервативний один слот.
- Робоче очікування на допуск до провайдера 8–25 с; ручні тести не блокують редакційну роботу й не погіршують статус зайнятого провайдера.
- Ліміт 2 платних спроб рахує тільки реально допущені запити; зайнятість шлюзу більше не підвищує `QUALITY_RETRY`.
- `AI_CAPACITY_WAIT` дає короткий повторний запуск без списання редакторських спроб; HTTP 404/410 `MODEL_UNSUPPORTED` не повертається автоматично до маршрутизації без успішного ручного probe.
- Порожні/невалідні відповіді після фактичного виклику й далі проходять строгий QA.

## 2. Редакційний відбір CTRL+UA (2.3.43)

- Зафіксовано власником неприйнятну публікацію CTRL+UA, Telegram #2060, article_id 106482, Hackaday HomeView repair teardown, опублікована 19.11.2026 14:37 Київ.
- Точковий source-only guard відсікає статті-інструкції про розбирання/ремонт, які перелічують не менш ніж чотири процедурні технічні сигнали і не мають підтвердженого значущого результату для читача.
- Guard спрацьовує до платного AI-відбору та повторно перед Telegram-публікацією вже підготовленого READY матеріалу.
- Не встановлює загальної заборони на Apple/iFixit/інженерію/ремонтопридатність: офіційні оцінки ремонтопридатності, підтверджені поліпшення модульності, відкликання через безпеку, рішення регуляторів залишаються на редакційному розгляді.
- Операторський READ-ONLY replay статті #106482 повернув `SCIENCE_TEARDOWN_PROCEDURE_NO_READER_NEWS_2343`; локальні 66 релевантних тестів пройдено.

## 3. Незмінні безпекові та продуктові вимоги

- Всі три канали: **CTRL+UA, ПРОДАНО!, ГРОМАДИ**; мінімальні інтервали **30 / 30 / 5 хв**. Жодного форсування кількості публікацій.
- OpenRouter основний; ліміти **$3 за добу / $20 за місяць**, максимум дві реально допущені платні спроби за виклик та $0.006 на gateway invocation збережено.
- Історія Telegram **COMMITTED**, два старі **UNKNOWN**, захист від дублів/помилкових повторів; ніяких автопересилань, видалення старих постів чи зміни операторської `Data`.
- Майбутній Portable не включає жодної операторської бази, токенів, ключів чи секретів. Не запускати одночасно дві копії на одній Data.
- Content Tool і його дані не змінюються. Автоматичне віддалене встановлення не виконується.

## 4. Релізні гейти

1. Всі файли версії `VERSION.txt`, `PUBLIC_VERSION.txt`, `V2_VERSION.txt`, `telegram_autopilot/__init__.py`, `telegram_autopilot/v2/__init__.py` мають збігатися з `2.3.43`.
2. Незалежний GitHub Actions CI: Ubuntu Python 3.12, Windows Python 3.11/3.12/3.13, включно із source-only guard та AI Gateway регресіями.
3. **Повний нативний** Windows Portable ZIP із `.exe`, вбудованим Python, UI startup і migration/Codex regression; Microsoft Defender scan і SHA-256/CRC. **Не випускати patch/overlay замість Portable**.
4. Після перевіреного ZIP оператор вручну зупиняє стару версію, робить резервну копію актуальної Data, розпаковує ZIP у НОВУ папку, зберігає найновіший Telegram ledger і запускає тільки один екземпляр. Жодних автоматичних змін Data на стороні помічника.
5. Реальне LIVE-приймання редакційної якості й AI після встановлення лишається окремим гейтом. Не називати код/CI/Windows build доказом якості опублікованих матеріалів.
