# Autopilot 2.1.12 — Startup and monitoring safety hotfix

- **First-run launch:** optional Codex SDK installation no longer runs before the normal main application. The compact Windows Portable UI and existing configured Gemini/Groq/etc. models start without waiting for a network-based installer. Explicit `UA_FREE_CODEX_BOOTSTRAP_ONLY=1` remains available for controlled CI provisioning; no user actions required. Codex is not automatically provisioned on regular launches.
- **Monitoring cadence:** one-time, idempotent per-channel DB migration changes monitoring channels at the old 15-minute baseline to 30 minutes, preserving explicit nondefault intervals, editorial channels, existing Data and published ledger. The value stays operator-editable in the settings.
- **Temporal gate:** final monitoring QA rejects texts that simultaneously present closed/reopened status as current without resolving the temporal phase. The original source and channel editor still decide which current status to publish.
- **Deferred from original broad roadmap:** fully configurable exclusion of nationally sourced reposts and evidence-level rejection of invented local consequences. These require an explicit source/provenance and local-fact policy with robust live examples; simple name-keyword blocking would suppress valid local posts. Neither is claimed fixed by 2.1.12. The 2.1.13 language cleanup is also not included.
- Release must pass Windows CI, native Portable smoke and live operator acceptance; do not claim all previous editorial problems are solved. Upgrade manually retaining Data, credentials and 2.1.11 rollback.
