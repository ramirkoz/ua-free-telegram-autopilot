# Autopilot 2.2.49 — прискорення комерційних джерел без пропуску нових матеріалів

## Підстава
LIVE оператора 28.10.2026 17:07 Київ: встановлено 2.2.48, 3/3 воркери й колектори RUNNING, 30 дописів сьогодні, 856 Telegram COMMITTED / 1 FAILED / 1 UNKNOWN. «ПРОДАНО!» залишається DEGRADED: Shots і Ads of the World давали 70-секундні тайм-аути, за новий цикл +1 матеріал. Глобальна помилка `rss_enrich_eligible` після 2.2.48 не спостерігається.

## Зміни
- Лише для комерційного PAGE: перед повною мережевою гідратацією кожного посилання перевіряємо, чи такий URL уже є в канонічній базі цього каналу. Відомі посилання пропускаємо; нові йдуть через той самий колектор, медіа й редакційні фільтри.
- Для повільних PAGE без публікацій зберігаємо початкову глибину перегляду посилань (72 у профілі оператора), але обмежуємо кількість дорогих завантажень сторінок до 4. Раніше скорочення scan до 12 могло приховати новий матеріал нижче списку.
- Додали новий необов'язковий параметр `page_url_eligible` у `collector.collect_source`, `strict_ingest.collect_strict`, `telegram_ingest_policy._collect_current` та production-виклик `bounded_ingest`, з регресійними тестами реального Telegram hook, щоб не повторити збій 2.2.47.
- **Не змінено:** список джерел, їхній пріоритет, cooldown/HTTP403/429, дата/TTL-політика, редакційні правила української, дедуплікацію на рівні фактів, зв'язування Telegram-медіа, Data, SQLite та незмінність COMMITTED/UNKNOWN, графіки 45/30/5, OpenRouter $3/добу й $20/місяць.

## Межі й перевірка
Фактичне прискорення Shots/Ads of the World не гарантоване: початкове завантаження сторінки/публічних feed може лишатися повільним. Новий алгоритм не дає права обходити блокування сайтів. Семантичний dedupe_shadow залишається лише діагностикою: автоматичне блокування за схожістю без перевірки події заборонене.

Випуск лише після 4/4 CI, Windows Portable/Defender, official main release з перевіреним ZIP та SHA256. Користувач зупиняє попередній екземпляр, копіює **всю** Data до нової Portable папки й запускає один процес. Потім потрібен окремий LIVE acceptance: 2.2.49, 3/3+3/3, фактичні нові PAGE-джерела й тривалість збору, повний журнал доставок, UNKNOWN-карантин і реальна якість тексту.
