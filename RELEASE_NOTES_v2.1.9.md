# Autopilot 2.1.9 — Conservative cross-source event identity

- Strengthen the universal commercial-editorial event fingerprint for independently sourced reports that describe the same named actor, specific product/object and multiple shared underlying facts, even when broad site-text overlap is weak. This is deliberately conservative and supplements existing same-event and ledger safeguards; no brand or channel names are encoded in the matcher.
- Regression fixtures distinguish an overlapping actor/object/facts event from unrelated product releases by the same company and from generic syndicated site boilerplate.
- Existing published delivery records remain immutable; no Telegram message is deleted or replaced automatically. No replay of previously published or manually deleted posts.
- Candidate source media are still validated by existing media policy, and 2.1.8 source-page recovery remains in place. This does not establish comprehensive cross-source quality ranking or automatically merge all multilingual paraphrases. Quality selection before publication requires further live operator QA.
- 2.1.9 technical release is distinct from confirmed live editorial acceptance. Preserve Data, credentials and delivery journal during manual Windows Portable upgrade.
