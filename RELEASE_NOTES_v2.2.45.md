# Autopilot 2.2.45 — українська граматика після перекладу

## Проблема, відтворена з Telegram
У CTRL+UA 27 жовтня після перекладу англомовної новини про поліцію США з'явилося речення: «Поліція США дедалі частіше зупиняє водіїв за підозрою, який висуває штучний інтелект». Відносний займенник «який» не узгоджується зі словом «підозрою», і зрозумілість страждає. Подібні ризики можливі й у «ПРОДАНО!» та «ГРОМАДИ».

## Реалізовано
- Додано вказівки для редактора **всіх каналів** перевіряти рід, число, відмінки, відносні займенники, присудок і природний синтаксис українського речення ПІСЛЯ перекладу, а не підміняти англомовні закінчення механічно.
- Введено вузький, детермінований **high-confidence блокувальник** для спостережуваної помилки та деяких аналогічних очевидних неузгоджень. Він не змінює текст автоматично, не добирає нових фактів, не чіпає цитати, імена, дати, цифри, контакти чи причинність.
- Перевірка включена у наявну валідацію автора, у вже наявного довіреного фінального редактора й у незалежний фінальний шлюз **перед Telegram**, зокрема для старих READY. Якщо текст не вдалося виправити без порушення фактів, автопублікацію заборонено.
- Дозволені правильні форми на зразок «програму, яка», «компанією, яку», «згідно зі звітом» і «згідно із звітом». Немає універсального переписування усіх відмінків регулярними виразами. Решта граматики контролюється наявним редактором та, за наявності, локальним LanguageTool.
- Немає нових AI-провайдерів, окремих перекладацьких API чи додаткового безумовного AI-проходу. Поточні бюджети, джерела, ритм публікацій, захист дат, дублів і доставка збережені.

## Тести та приймання
- Регресія з реальної помилки «підозрою, який» та 24 варіантів однозначних неузгоджень.
- Перевірки на нешкідливі конструкції та на заборону відправлення помилкового READY на кожному з трьох каналів.
- Обов'язково CI Ubuntu + Windows 3.11/3.12/3.13, Windows Portable з тестом GUI/Defender, SHA256, офіційний тег GitHub.
- Встановлення без втрати `Data`: зупинити попередню програму, зробити повну копію `Data`, розпакувати новий ZIP в окрему директорію, скопіювати `Data`, запустити один екземпляр. Перевірити LIVE-телеметрію та приклади нових українських постів вручну.
- **Обмеження:** жоден простий regex не вміє оцінити кожне узгодження у всіх українських реченнях. Реліз посилює наявну редакторську перевірку та блокує підтверджений клас дефекту, але не дає математичної гарантії граматичної бездоганності.
