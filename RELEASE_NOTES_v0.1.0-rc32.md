# UA FREE Telegram Autopilot v0.1.0-rc32

- Media publication now requires semantic evidence that the selected image/video belongs to the article event. Position and image size may rank media but cannot make unrelated media eligible.
- Autopilot prefers no image over an unrelated source-page/recommendation image.
- Editorial rewrites are impersonal: meta-commentary about an article author/reviewer/editor/journalist is removed or rejected; factual participants and official quoted sources remain allowed.
- Every publication with an original URL ends with a clickable Telegram text-link labelled `Джерело`; the raw URL is not printed in the body.
- RC31 UI responsiveness changes and the RC30 production/QA architecture are retained.
