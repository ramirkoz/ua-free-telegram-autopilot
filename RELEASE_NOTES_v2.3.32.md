Статус: **Windows Portable / Source — кандидат на операторську QA**, не встановлено автоматично. Попередня підтверджена LIVE версія 2.3.31. Реліз в основну GitHub-гілку та тег не виконано. Гілка v2.3.32 включає успадковані (ще не об’єднані) зміни 2.3.30/2.3.31.

## Головне

- **P0 ГРОМАДИ:** новий source-owned veto для зшитих коротких оперативних авіаційних сигналів «реактив між… / мопед на…», навіть якщо в них немає дієслова «летить» чи «пролітає». Не пропускати їх через рерайт. Зберегти старі коди діагностики інших активних загроз і нормальні офіційні повідомлення про підтверджені наслідки.
- **ГРОМАДИ:** блок майбутніх церемоній, окремих зборів коштів, анонсів гарячих ліній, святкових привітань, загальних побутових/медичних порад, непідтвердженої географії ДТП, нерегіональних сюжетів та необґрунтованих звинувачень. Новини про підтверджені наслідки, евакуацію, графіки послуг, місцеві рішення, транспорт і виставки зберігаються.
- **CTRL+UA:** блок покрокових інструкцій із роботосимулятора, самостійних анонсів епізодів подкастів, порад щодо купівлі дискретної відеокарти. Зберегти наукові відкриття, реальні випробування, нові робототехнічні технології.
- **ПРОДАНО!:** блок рейтингів рибних закладів по штатах, звичайних продуктових порівнянь, довідників із гоночних прапорів, чуток про доступність Audi в США та рутинних нових колірних варіантів без нової механіки. Зберегти авторське мистецтво, цікаві дизайнерські предмети, нові технологічні продукти та змістовні авторські добірки.
- **Фінальний QA:** перехоплення пошкоджених посилань («за посиланням: або», порожнє «На сайті...:») та помилкового перетворення неперевіреної географії ДТП на загальноукраїнське твердження. Source-only і prepublish діють незалежно для старих READY.

Не змінюються Data, джерела, інтервали **30/30/5**, AI-бюджети, Telegram ledger, історичні дописи, дві захищені доставки UNKNOWN, ключі доступу, налаштування оператора та рестартна свіжість. Жодного автоматичного replay, зміни графіка чи масового backfill.

**Офіційний релізний GO залишається відкритим до**: точного CI GitHub + Windows Defender/first-run; незалежного Source→photo/video ownership QA для Naruto #297, 10-фото галерей #4994/#5046/#5056 і відео #1948; аналізу same-day source retention при перезапуску #306; 24–48 год природного LIVE із контролем трьох каналів після встановлення.
