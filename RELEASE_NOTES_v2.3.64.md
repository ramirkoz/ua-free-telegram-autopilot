# Autopilot 2.3.64 — support-only hybrid routing

Owner contract: production text writing, rewriting and final editing use OpenRouter exclusively. If it is unavailable, writing is deferred; no silent direct-model authoring. Cached writer checkpoints from other providers are not reused. Reader Gate remains on OpenRouter until direct models pass a comparative editorial-quality trial.

Bounded pilot for validated editorial/monitoring selection and value gates: exact Groq Qwen/GPT-OSS, NVIDIA Ultra and Cloudflare GLM models, one direct HTTP request per gateway invocation, then existing OpenRouter fallback. Existing source, policy, fact, quality, delivery and duplicate gates remain mandatory. Direct responses must also satisfy a strict support JSON contract; incomplete scores do not become zero silently. Existing exact selector cache can reuse validated direct decisions. A direct model never produces or rewrites publishable copy. Gemini alias, reasoning-only Cloudflare Gemma and local model are excluded from the pilot; no credentials or operator settings changed.

Persistent admission ceilings per direct provider: 8 requests/hour, 60/24h, 400,000 reserved UTF-8 bytes/24h (including framing/output allowance), maximum 32,000 source-prompt bytes per request. These are local pilot safeguards, not verified provider account quotas or guarantees of free billing. Only use free-tier credentials. Existing global OpenRouter budgets and per-article caps remain unchanged. No hidden direct HTTP retries or model fallback. Runtime telemetry distinguishes recorded direct support, paid support and non-OpenRouter copy calls. Existing monitoring intervals 30/30/5 and all publication rules remain unchanged.

No new source truncation, automatic free writer qualification, standalone fact-extraction AI or semantic duplicate model introduced. Real authenticated editorial quality, provider-account billing and savings remain to be measured in LIVE. Native Windows CI/official release remains deferred. Keep 2.3.63 rollback.
