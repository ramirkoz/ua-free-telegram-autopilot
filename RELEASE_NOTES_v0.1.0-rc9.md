# UA FREE Telegram Autopilot v0.1.0-rc9

## Direct Telegram format hotfix

RC9 зберігає номер версії та сумісність з наявною `Data`, але production-формат спрощено після live-тестів.

### Публікація
- Telegraph повністю вилучено з production write path;
- готовий пост публікується безпосередньо в Telegram;
- якщо є надійне медіа: максимум один медіафайл і жорсткий ліміт поста 900 символів;
- якщо медіа немає: одне текстове повідомлення з hard limit 4096 символів;
- ліміт визначається до AI-рерайту за фактичним результатом Media Engine;
- AI-вивід, що обривається посеред речення/думки, не публікується і проходить failover/rewrite повторно.

### Рерайт
- окремого заголовка в Telegram-пості більше немає; текст починається одразу з головного факту;
- додано адаптивний readability verifier: хороший перший рерайт публікується без додаткових витрат, а посередній запускає bounded second-pass через інший доступний AI-провайдер;
- один AI-запит на професійний український научпоп/техножурналістський пост;
- з медіа цільовий обсяг 700–880 символів, hard limit 900;
- без медіа рекомендований обсяг 1800–3400 символів за наявності достатніх фактів, hard limit 4096;
- readability gate контролює короткі абзаци, перевантажені речення, кальковану українську та суцільні стіни тексту;
- збільшені bounded output budgets, щоб модель не зрізала останнє речення на межі токенів;
- без рекламної мови, клікбейту, вигаданого бекграунду та буквального машинного перекладу;
- роки і числа, яких немає у джерелі, блокують рерайт;
- відносні часові формулювання прив'язуються до `source_published_at`.

### Media
- article-only extraction;
- related/recommended stories не входять до кандидатів;
- `Click to follow`, Google-follow cards, банери, promo, logos та tracking assets відкидаються;
- у Telegram використовується лише один найкращий hero.

### Сумісність
- старі поля Telegraph у SQLite лишаються лише для безпечної сумісності з існуючою `Data` та історією;
- внутрішнє поле заголовка використовується лише як cache marker для сумісності зі старим сервісом і не показується читачу;
- нові публікації Telegraph не використовують.
