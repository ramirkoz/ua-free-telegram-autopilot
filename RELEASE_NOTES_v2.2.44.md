# Autopilot 2.2.44 — один перевірений факт / одна локальна подія

## Виправлена помилка
27 жовтня 2026 року «ЗАПОРІЖЖЯ | ГРОМАДИ» розмістили два дописи про **перший місяць роботи Простору турботи про ветерана в Запоріжжі**: один за повідомленням ОВА о 15:22, другий за повідомленням «Запоріжжя Online» о 16:58. В обох використано відео тієї самої історії, але акценти текстів різні (сукупна статистика послуг проти особистої історії ветерана). Механізми порівняння текстів не впізнали спільну подію.

## Що змінено
- Окрема високоточна, основана на першоджерелах ідентичність події для **першого місяця роботи громадського закладу/сервісу**: потрібен збіг назви закладу, населеного пункту, етапу «перший місяць» і дати повідомлення в межах 48 годин між різними джерелами.
- Перевірка виконується **перед AI і перед Telegram**, включно з історією вже підтверджених публікацій каналу.
- Відмінний виклад, статистика, коментар відвідувача чи інший монтаж того самого відео самі собою не створюють нової події. Водночас один і той самий файл відео без збігу фактичної події не є достатньою підставою для блокування.
- Достовірне відкриття нової філії, запуск нової послуги, інше місце або пізніший місячний підсумок залишаються окремими інформаційними приводами.
- Нова перевірка діє для режиму `MONITORING`, не змінюючи CTRL+UA, ПРОДАНО!, джерела, інтервали, фактчекінг, 7-добову оперативну історію або журнал підтверджених доставок Telegram. Наявні дублікати в Telegram автоматично не видаляються.

## Перевірка і встановлення
- Регресійні тести відтворюють два операторські дописи та негативні сценарії.
- Обов'язкові бар'єри релізу: повний CI Ubuntu + Windows Python 3.11/3.12/3.13, Windows Portable GUI запуск, Microsoft Defender і SHA256.
- Зупинити попередню програму, повністю зберегти `Data`, розпакувати новий Portable ZIP в іншу папку, перенести `Data` без змін, запустити один процес і підтвердити роботу 3/3 колекторів/воркерів, без дублювання нових подій.
- Окремий відомий дефект узгодження відмінків українською після перекладу не входить у цей точковий реліз і потребує своєї перевірки, щоб не змішувати незалежні ризикові зміни.
