# Autopilot 2.2.10 — Операторські редакційні виправлення

Дата: 21 жовтня 2026

## Що виправлено

- Для моніторингових каналів із правилом `[LIVE_NOW_RC96]` додано незалежний від AI контроль вихідного тексту: поточні повідомлення про бойові позиції та просування, загальні добірки вакансій і нецивільна риторика про втрати військових не повинні проходити у громадський канал.
- Редакційний захист повторно спрацьовує безпосередньо перед надсиланням. Підготовлені раніше матеріали не обходять нові правила.
- У додатковому міжджерельному шарі перевіряється ідентичність локального об'єкта, стадії встановлення та району для дубльованих повідомлень про модульні укриття. Текст, джерело та різні фотографії самі по собі більше не створюють нову подію. Відкриття після монтажу та різні адреси залишаються окремими подіями.
- Додано регресійні сценарії для шести операторських скриншотів і контрольні контрприклади.

## Межі випуску

- Це локальне програмне виправлення. Воно не видаляє й не повторює вже опубліковані Telegram-дописи, не змінює особисті налаштування інтервалу публікацій та не торкається Data/секретів.
- Показник затору CTRL+UA і READY-буфер потребують окремої верифікації фактичного операторського інтервалу публікацій. У 2.2.10 не відключається ліміт READY і не прискорюється Telegram-відправка ціною спаму.
- GitHub CI, Windows Release і окреме LIVE-приймання підтверджуються тільки фактичними результатами, не цим документом.
